Live Transcriber - راهنمای ساخت APK

1. Android Studio را باز کنید و File > Open را بزنید و پوشه LiveTranscriber را انتخاب کنید.
2. صبر کنید تا Gradle Sync کامل شود (اولین بار چند دقیقه طول می‌کشد).
   اگر پیغام Gradle wrapper دیدید، گزینه Use Gradle from Android Studio / Create wrapper را انتخاب کنید.
3. از منوی Build > Build Bundle(s) / APK(s) > Build APK(s) را بزنید.
4. فایل app-debug.apk را از مسیر app/build/outputs/apk/debug روی گوشی کپی و نصب کنید.
5. در تنظیمات اندروید، نصب از منابع ناشناس را برای برنامه مدیریت فایل مجاز کنید.
